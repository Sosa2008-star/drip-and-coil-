# Drip & Coil v2

Это готовый фронтенд-прототип магазина для GitHub Pages.

## Важно
GitHub Pages — статический хостинг. Он отлично подходит для интерфейса, но **не является сервером для безопасной авторизации, базы клиентов, реального админ-пароля и серверных уведомлений**.

В этой версии:
- каталог и фильтры работают;
- корзина работает;
- локальный профиль/регистрация работает;
- локальные заказы и статусы работают;
- админ-панель и изменение статуса работают локально;
- поддержка ведёт в Telegram @s88xy;
- есть категории Электроника / Вейпы / Жидкости / Одежда;
- возрастно-ограниченные категории не продаются в демо-режиме без legal age check.

Для полноценного запуска нужна серверная часть (например, Supabase/Firebase/свой backend) с Auth + DB + Storage + RLS.
